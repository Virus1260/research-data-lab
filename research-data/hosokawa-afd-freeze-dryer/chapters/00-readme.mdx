## Critical framing: read this before anything else

**The Hosokawa AFD is not a conventional tray or shelf freeze dryer.** This represents the primary insight of this research.

Almost everything written about pharmaceutical freeze drying describes a **static tray/shelf lyophilizer**: vials sit motionless on heated or cooled shelves inside a rectangular chamber, with a separate refrigerated ice condenser alongside.

The Hosokawa AFD is a **dynamic, agitated, one-pot freeze dryer**: a jacketed, downward-conical vessel (mechanically related to the Nauta conical screw mixer) in which product is frozen while being stirred, then dried while still being stirred. Water vapor discharges through a dust collector rather than settling on static shelves. This is confirmed by Hosokawa's publications and two direct patents:

- **NL1022668C2 / EP1601919B1**, "Stirred freeze drying," Hosokawa Micron B.V., filed 2003: foundational patent for this product family.
- **NL2026893B1 / WO2022103268A1**, "Freeze dryer and method for freeze drying," Hosokawa Micron B.V., filed 2020, granted 2022: describes current material-collector and valve configuration.

File `03` details patent disclosures and separates them from generic textbook concepts. Where Hosokawa does not publish dimensions or hardware models, this package provides engineering methods to calculate them directly.

## Key published design constant: 50% working-volume ratio

Hosokawa's published "Models & Capacities" table gives maximum batch volume as **exactly 50% of nominal vessel volume across all 10 published models** (0.5 L to 750 L batch size). File `05` Section 1a and Chapter 25 implement this constant: nominal vessel volume equals 2x target batch volume. Conical volume scales with height cubed ($h_{\text{fill}} = 0.794 \cdot h$), requiring substantial vertical freeboard for agitated powder motion, vapor disengagement, and foaming margin.
