# 20 — Control System Architecture & Safety Separation (BPCS vs. SIS)

In pharmaceutical freeze-drying systems, a modern industrial control system is not one giant computer running everything. It is **two strictly separated hardware systems sharing a single supervisory HMI display.**

This chapter outlines the four architectural tiers, explains why standard **IEC 61511** mandates the physical separation between process execution and human safety, and details the industrial networking standards required for cGMP compliance.

## 1. The Core Axiom: BPCS vs. SIS Isolation

Every process control failure investigation in chemical and biopharmaceutical history points to a single recurring flaw: *when the system programmed to operate the machine is also entrusted with protecting human operators from it, a single CPU glitch or software corruption eliminates both simultaneously.*

To prevent common-cause failures, **IEC 61511** enforces strict hardware segregation:

### Tier 1: Basic Process Control System (BPCS)
- **Role**: The operational brain. Executes the ISA-88 recipe sequence, runs proportional-integral-derivative (PID) temperature loops, throttles vacuum control valves, and collects batch sensor logs.
- **Worst-Case Failure**: If the BPCS PLC freezes or encounters a software crash, the worst possible consequence is a **spoiled product batch**.

### Tier 2: Safety Instrumented System (SIS)
- **Role**: The independent guardian. A dedicated, deterministic, failsafe system whose sole mandate is to bring the equipment into a safe state if a critical hazard develops.
- **Independence**: The SIS uses completely dedicated sensors (`ZS-101`, `PSH-101`), dedicated I/O cards, and its own certified safety CPU or hardwired safety relays.
- **Immunity**: If the BPCS completely loses power, crashes its operating system, or experiences an infinite software loop, the SIS continues functioning without interruption.

## 2. Hardwired Emergency Stop Philosophy (`ESD-001`)

On this freeze dryer, emergency shutdown circuits are **electromechanically hardwired**:
- Pressing an emergency stop pushbutton or tripping a vessel cover limit switch de-energizes a dual-channel certified safety relay (e.g., Pilz PNOZ or Siemens SIRIUS).
- The relay physically drops out primary contactors feeding power to the agitator VFD, the circulation thermal heaters, and the main vacuum pump motors.
- The signal **never passes through an ordinary software register or PLC memory bit**. Software can observe the trip, but software cannot override or clear the physical interlock.

## 3. The Four-Tier Automation Hierarchy

<AutomationHierarchyChart />

### Layer 1: Field Devices
Physical sensors, transmitters, and motorized actuators situated across the skid:
- **BPCS Devices**: `PIT-101A/B`, `TT-201/202`, `JIT-101`, `PV-102`, `XV-103/105`.
- **SIS Devices**: Vessel cover switch `ZS-101`, overpressure switch `PSH-101`, gas leak detector `AIT-001`.

### Layer 2: I/O Interface
- Signals land on isolated terminal racks with optical isolation and surge suppression.
- Safety signals land exclusively on yellow, fail-safe I/O slices with internal clock cross-checking.

### Layer 3: Programmable Automation Controllers
- **BPCS Controller**: Siemens S7-1500 or Rockwell ControlLogix executing structured ladder logic, function blocks, and ISA-88 recipe phase states.
- **SIS Controller**: Siemens S7-1500F (Failsafe) or dedicated hardware safety relays.

### Layer 4: Supervisory SCADA & Data Historian
- Operator interface displaying real-time mimic diagrams, alarm banners, and interactive trend charts.
- **Electronic Batch Records (EBR)**: 21 CFR Part 11 compliant SQL historian logging every process variable every 1,000 ms with cryptographic timestamps and audit signatures.

## 4. Communication & Network Architecture

- **Industrial Fieldbus**: **PROFINET** (100 Mbps full duplex) connects the PLC rack to remote I/O distributed on the machine frame and the agitator Variable Frequency Drive (VFD).
- **Safety Protocol**: **PROFIsafe** encapsulates safety telegrams inside standard Ethernet packets with sequence numbering, CRC verification, and watchdog timeouts. If communication degrades, the system defaults to a safe shutdown.
- **SCADA Uplink**: OPC UA (Open Platform Communications Unified Architecture) feeds batch metadata to higher-level Manufacturing Execution Systems (MES).
